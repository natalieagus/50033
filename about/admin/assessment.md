| Component                        |  Weight | Details                                                                                                                                                          |
| -------------------------------- | ------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [**Game Project**](game-project) | **45%** | Term-long **group project** with **4 checkpoints**. Please read about the [**Effective Project Grade**](game-project#effective-project-grade) before proceeding. |
| **Individual Homework**          |  **5%** | Individual presentation about your favourite game.                                                                                                               |
| **Midterm Examination**          | **30%** | Conducted in **Week 8**. Consists of **Part A: Concepts (15%)**, and **Part B: Game Jam (15%)**. See [below](#midterm-examination).                              |
| **Lab Checkoffs**                | **20%** | **Lab Submissions (15%)** and **Group Presentation (5%)**. See [below](#lab-checkoffs).                                                                          |
| **End-of-Term Course Survey**    |  **2%** | Completion of the end-of-term course survey.                                                                                                                     |

### Midterm Examination

| Part                 |  Weight | Format                                                                                                                                                                                                                                                                                        |
| -------------------- | ------: | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Part A: Concepts** | **15%** | 1.5-hour, paper-based examination covering both game design concepts and Unity Lab concepts.                                                                                                                                                                                                  |
| **Part B: Game Jam** | **15%** | Take-home assessment, to be completed within **48 hours**. You will be given a starter Unity asset and a list of requirements. You may implement the game in any way you choose, but must be prepared to justify selected features using game-design concepts taught in the first five weeks. |

### Lab Checkoffs

| Component            |  Weight | Details                                                                                                     |
| -------------------- | ------: | ----------------------------------------------------------------------------------------------------------- |
| **Lab Submissions**  | **15%** | Five submissions, worth **3% each**. Optional **pair work**. Submit a recording + repo link via eDimension. |
| **Lab Presentation** |  **5%** | One lab presentation, marks are group-based. Randomly selected during **Weeks 2–6**.                        |
